zo- / zoo-
Prefix: Djur-, levande. Av grek. zoon = djur. Ex: zoonos = sjukdom som smittar från djur till människa.
Zona
Subst.: Gördel; t.ex. zona orbicularis (ledkapselns ringbelt), zona pellucida (äggcellens omgivning). Sv: zon, bälte. Eng: zone, zona. Av grek./lat. zona = gördel, bälte.
Zoofil dermatofyt
Subst.: Hudsvamp (dermatofyt) som har djur som naturlig värd men kan smitta människor och då ofta ge kraftig inflammation. Eng: zoophilic dermatophyte. Av gr. zoon = djur + philos = vän + dermatofyt. Jfr Dermatofyt, Tinea.
Zoonos
Subst., -en; pl. -er: Infektionssjukdom som kan överföras mellan djur och människa. Eng: zoonosis. Av gr. zoon = djur + nosos = sjukdom. Jfr Vektor, Smitta.
zyg- / zygo-
Prefix: Ok-, par, förening; okben. Av grek. zygon = ok. Ex: zygot = befruktad äggcell (förening av två könsceller).
Zygoma
Subst.: Ok; os zygomaticum = kindbenet. Sv: kindbenet, zygoma. Eng: zygoma, cheekbone. Lekman: kindbenet. Av grek. zygon = ok, juk; okbågen förbinder som ett ok.
Zygomaticus
Adj.: Okliknande; t.ex. m. zygomaticus major/minor, arcus zygomaticus, os zygomaticum. Sv: zygomatisk. Eng: zygomatic. Av grek. zygon = ok.
zym- / zymo-
Prefix: Jäsning-, enzym. Av grek. zyme = surdeg, jäsning. Ex: enzym = ämne som påskyndar kemiska reaktioner.

Termer baserade på Terminologia Anatomica, Nomina Anatomica och svensk medicinsk ordbok.
