Medicinska ändelser (suffix)

Medicinska och anatomiska ändelser (suffix) ur latinet och grekiskan – som -it, -emi och -ektomi – med betydelse, ursprung och exempel. Sök i hela ordlistan nedan, eller bläddra vidare.

-ad
suffix I riktning mot, -åt (anatomisk riktningsterm). Av lat. -ad = mot, till. Ex: cephalad = mot huvudet; caudad = mot svansänden; ventrad = mot buksidan.
-agra
suffix akut smärta, anfall. Av grek. agra = gripande, anfall. Ex: podagra = akut gikt i stortån (portvinstå).
-al / -an / -ar / -ic
suffix anatomiska adjektivändelser – som hör till, är belägen vid. Av lat. -alis, -anus, -aris, -icus. Ex: renalis = njur-; cardiacus = hjärt-; muscularis = muskel-.
-algia / -algi
suffix smärta, värk. Av grek. algos = smärta. Ex: myalgi = muskelsmärta; neuralgi = nervsmärta. Jfr -dyni.
-angio
suffix kärl- (slutled). Av grek. angeion = kärl. Ex: lymfangiom = godartad tumör i lymfkärl. Jfr prefix angio-.
-ase / -as
suffix enzym. Efter diastas, det första namngivna enzymet. Ex: amylas = stärkelsespjälkande enzym; laktas; polymeras.
-asthenia / -asteni
suffix svaghet, kraftlöshet. Av grek. a- = utan + sthenos = styrka. Ex: myasteni = muskelsvaghet; neurasteni. Jfr -steni.
-atrophy / -atrofi
suffix förtvining, näringsbrist i vävnad. Av grek. a- = utan + trophe = näring. Ex: muskelatrofi = förtvinad muskel. Jfr -trofi.
-blast
suffix omogen cell, modercell under utveckling. Av grek. blastos = grodd, gröddel. Ex: erytroblast = förstadium till röd blodkropp; fibroblast.
-calcinosis / -kalcinos
suffix förkalkning av vävnad. Av lat. calx (calcis) = kalk. Ex: nefrokalcinos = kalkutfällning i njurarna.
-capnia / -kapni
suffix koldioxidhalt i blodet. Av grek. kapnos = rök, os. Ex: hyperkapni = förhöjd koldioxidhalt i blodet.
-carcinoma / -karcinom
suffix cancer utgången från epitelvävnad. Av grek. karkinos = kräfta. Ex: adenokarcinom = körtelcellscancer.
-cele
suffix bråck, utbuktning, vätskefylld svullnad. Av grek. kele = bråck, svulst. Ex: rektocele = ändtarmsbråck; hydrocele = vattenbråck.
-centesis / -centes
suffix punktion, instick för att tappa ut vätska. Av grek. kentesis = stick. Ex: paracentes = buktappning; torakocentes = lungsäckspunktion.
-cholia / -koli
suffix tillstånd rörande galla. Av grek. khole = galla. Ex: akoli = brist på galla.
-chrome / -krom
suffix färg, cellulärt pigment. Av grek. khroma = färg. Ex: cytokrom = färgat protein i cellandningen. Jfr -kromi.
-chromia / -kromi
suffix färg, pigmentering. Av grek. khroma = färg. Ex: heterokromi = olikfärgade ögon; hypokromi = blek färg (på blodkroppar).
-chylia / -kyli
suffix tillstånd rörande mag-/mjölksaft. Av grek. khylos = saft. Ex: akyli = avsaknad av magsaft.
-clasis / -clasia / -klasi
suffix brott, krossning, nedbrytning (även avsiktlig kirurgisk brytning). Av grek. klasis = brytning. Ex: osteoklasi = (kirurgisk) brytning av felvuxet ben. Jfr -klast.
-clast / -klast
suffix cell som bryter ner eller resorberar vävnad. Av grek. klastos = bruten. Ex: osteoklast = bennedbrytande cell; odontoklast. Jfr -klasi.
-clysis / -klys

-cyte / -cyt
suffix mogen, specialiserad cell. Av grek. kytos = ihålighet, cell. Ex: hepatocyt = levercell; trombocyt = blodplätt.
-cythemia / -cytemi

-dactyly / -daktyli

-dentia / -denti

-dermia / -dermi

-desis / -des

-dilation / -dilatation

-doxia / -doxi

-dynia / -dyni

-emesis / -emes

-esthesia / -estesi

-genesis / -genes

-globin / -globulin

-gnosis / -gnos

-gonia / -goni

-gram

-graph / -graf

-graphia / -grafi

-gusia / -geusia / -geusi

-iasis / -ias

-icterus / -ikterus

-in

-ism

-kinesia / -kinesi

-krin

-lalia / -lali

-lysis / -lys

-melia / -meli

suffix tillstånd rörande bröstvårtor. Av grek. thele = bröstvårta. Ex: polyteli = övertaliga bröstvårtor.
-therapia / -terapi
suffix medicinsk eller fysikalisk behandling. Av grek. therapeia = vård. Ex: kemoterapi = cytostatikabehandling; fysioterapi.
-thermia / -termi
suffix kroppstemperatur. Av grek. therme = värme. Ex: hypotermi = nedkylning; hypertermi = överhettning.
-thrombosis / -trombos
suffix blodproppsbildning. Av grek. thrombos = propp. Ex: sinustrombos; ventrombos.
-tocia / -toki
suffix förlossning, värkarbete. Av grek. tokos = födsel. Ex: dystoki = försvårad förlossning.
-tomia / -tomi
suffix operativt insnitt, klyvning utan borttagande. Av grek. tome = snitt. Ex: laparotomi = snitt genom bukväggen; osteotomi. Jfr -ektomi.
-tonia / -toni
suffix muskelspänning, tryck. Av grek. tonos = spänning. Ex: hypertoni = högt blodtryck/ökad muskelspänning; atoni = slapphet; dystoni.
-toxin
suffix biologiskt eller kemiskt gift. Av grek. toxikon = (pil)gift. Ex: endotoxin = bakteriegift; nefrotoxin = njurgift. Jfr -toxikos.
-toxism / -toxikos
suffix förgiftningstillstånd. Av grek. toxikon = gift. Ex: tyreotoxikos = akut överskott av sköldkörtelhormon. Jfr -toxin.
-tresia / -tresi
suffix hål, öppning (nästan alltid negerat). Av grek. tresis = perforering. Ex: atresi = medfödd tillslutning av hålorgan.
-tripsia / -tripsi
suffix mekanisk krossning av konkrement. Av grek. tripsis = krossning. Ex: litotripsi = stenkross med tryckvågor.
-trophia / -trofi
suffix tillväxt, cellstorlek, näringstillstånd. Av grek. trophe = näring. Ex: hypertrofi = förstoring av celler/vävnad. Jfr -atrofi.
-trophin / -tropin
suffix hormon som stimulerar eller styr ett annat organ. Av grek. trophe = näring / tropos = vändning. Ex: gonadotropin; somatotropin = tillväxthormon.
-tropic / -trop
suffix som har riktning mot, påverkar. Av grek. tropos = vändning, riktning. Ex: kronotrop = som påverkar hjärtats rytm; inotrop = som påverkar hjärtats kraft.
-ula / -ulus / -culum
suffix anatomiska diminutivändelser – liten variant av organet. Av lat. -ula, -ulus, -culum. Ex: venula = litet venöst kärl; divertikulum = liten utbuktning.
-uria / -uri
suffix sjuklig förändring i urinen, urinering. Av grek. ouron = urin. Ex: hematuri = blod i urinen; glukosuri = socker i urinen; polyuri.
-valva
suffix klaff, ventil. Av lat. valva = dörrhalva, klaff. Ex: valvula = liten klaff (t.ex. i ven eller hjärta).
-zyme / -zym
suffix enzym, jäsningsämne. Av grek. zyme = surdeg, jäsning. Ex: lysozym = bakteriedödande enzym. Jfr prefix zym-.

Termer, definitioner och stavning följer vedertagna standardverk inom anatomi och medicinsk terminologi: Terminologia Anatomica (FIPAT/IFAA), Nomina Anatomica, Gray’s Anatomy, Sobotta – Atlas of Human Anatomy, Svenska Akademiens ordbok (SAOB) samt etablerade svenska medicinska uppslagsverk och ordböcker. Diagnoser, koder och läkemedelsuppgifter har även stämts av mot Socialstyrelsens klassifikationer (ICD-10-SE) och FASS.
