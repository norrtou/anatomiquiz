Medicinska ändelser (suffix)

Medicinska och anatomiska ändelser (suffix) ur latinet och grekiskan – som -it, -emi och -ektomi – med betydelse, ursprung och exempel. Sök i hela ordlistan nedan, eller bläddra vidare.

-ad
suffix I riktning mot, -åt (anatomisk riktningsterm). Av lat. -ad = mot, till. Ex: cephalad = mot huvudet; caudad = mot svansänden; ventrad = mot buksidan.
-agra
suffix akut smärta, anfall. Av grek. agra = gripande, anfall. Ex: podagra = akut gikt i stortån (portvinstå).
-al / -an / -ar / -ic
suffix anatomiska adjektivändelser – som hör till, är belägen vid. Av lat. -alis, -anus, -aris, -icus. Ex: renalis = njur-; cardiacus = hjärt-; muscularis = muskel-.
-algia / -algi
suffix smärta, värk. Eng. -algia. Av grek. algos = smärta. Ex: myalgi = muskelsmärta; neuralgi = nervsmärta. Jfr -dyni.
-angio
suffix kärl- (slutled). Av grek. angeion = kärl. Ex: lymfangiom = godartad tumör i lymfkärl. Jfr prefix angio-.

suffix enzym. Eng. -ase. Efter diastas, det första namngivna enzymet. Ex: amylas = stärkelsespjälkande enzym; laktas; polymeras.

suffix kroppslig storleksavvikelse. Eng. -somia. Av grek. soma = kropp. Ex: makrosomi = onormalt stor kropp vid födseln.
-spasmus / -spasm
suffix ofrivillig kramp i muskulatur. Eng. -spasm. Av grek. spasmos = kramp. Ex: laryngospasm = stämbandskramp; blefarospasm = ögonlockskramp.
-stasis / -stas
suffix stillastående flöde, stagnation. Eng. -stasis. Av grek. stasis = stillastående. Ex: kolestas = gallstopp; hemostas = blodstillning.
-stat
suffix substans eller apparat som hämmar rörelse/tillväxt. Av grek. statos = stillastående. Ex: bakteriostatika = medel som hämmar bakterietillväxt; hemostat.
-stenosis / -stenos
suffix sjuklig förträngning av kanal eller öppning. Eng. -stenosis. Av grek. stenos = trång. Ex: pylorusstenos = magmunsförträngning; mitralisstenos.
-sthenia / -steni
suffix styrka, kraft (används oftast negerat). Eng. -sthenia. Av grek. sthenos = styrka. Ex: se -asteni (svaghet). Jfr -asteni.
-stigma
suffix punkt, märke, öppning. Av grek. stigma = märke, stick. Ex: astigmatism = brytningsfel där ljus inte samlas i en punkt.
-stoma
suffix anatomisk mun eller por. Av grek. stoma = mun, öppning. Ex: nefrostoma = öppning till njurbäckenet. Jfr -stomi.
-stomia / -stomi
suffix operativt anlagd öppning ut ur kroppen. Eng. -stomy. Av grek. stoma = mun, öppning. Ex: trakeostomi = andningshål på halsen; ileostomi. Jfr -stoma.
-syndrome / -syndrom
suffix samling av sjukdomstecken/symtom. Eng. syndrome. Av grek. syndrome = sammanlöpande. Ex: metabolt syndrom.
-tasis
suffix kirurgisk uttänjning, sträckbehandling. Av grek. tasis = sträckning. Ex: myotasis = muskelsträckning. Jfr -stas.
-thelia / -teli
suffix tillstånd rörande bröstvårtor. Eng. -thelia. Av grek. thele = bröstvårta. Ex: polyteli = övertaliga bröstvårtor.
-therapia / -terapi
suffix medicinsk eller fysikalisk behandling. Eng. -therapy. Av grek. therapeia = vård. Ex: kemoterapi = cytostatikabehandling; fysioterapi.
-thermia / -termi
suffix kroppstemperatur. Eng. -thermia. Av grek. therme = värme. Ex: hypotermi = nedkylning; hypertermi = överhettning.
-thrombosis / -trombos
suffix blodproppsbildning. Eng. -thrombosis. Av grek. thrombos = propp. Ex: sinustrombos; ventrombos.
-tocia / -toki
suffix förlossning, värkarbete. Eng. -tocia. Av grek. tokos = födsel. Ex: dystoki = försvårad förlossning.
-tomia / -tomi
suffix operativt insnitt, klyvning utan borttagande. Eng. -tomy. Av grek. tome = snitt. Ex: laparotomi = snitt genom bukväggen; osteotomi. Jfr -ektomi.
-tonia / -toni
suffix muskelspänning, tryck. Eng. -tonia. Av grek. tonos = spänning. Ex: hypertoni = högt blodtryck/ökad muskelspänning; atoni = slapphet; dystoni.
-toxin
suffix biologiskt eller kemiskt gift. Av grek. toxikon = (pil)gift. Ex: endotoxin = bakteriegift; nefrotoxin = njurgift. Jfr -toxikos.
-toxism / -toxikos
suffix förgiftningstillstånd. Eng. -toxicosis. Av grek. toxikon = gift. Ex: tyreotoxikos = akut överskott av sköldkörtelhormon. Jfr -toxin.
-tresia / -tresi
suffix hål, öppning (nästan alltid negerat). Eng. -tresia. Av grek. tresis = perforering. Ex: atresi = medfödd tillslutning av hålorgan.
-tripsia / -tripsi
suffix mekanisk krossning av konkrement. Eng. -tripsy. Av grek. tripsis = krossning. Ex: litotripsi = stenkross med tryckvågor.
-trophia / -trofi
suffix tillväxt, cellstorlek, näringstillstånd. Eng. -trophy. Av grek. trophe = näring. Ex: hypertrofi = förstoring av celler/vävnad. Jfr -atrofi.
-trophin / -tropin
suffix hormon som stimulerar eller styr ett annat organ. Av grek. trophe = näring / tropos = vändning. Ex: gonadotropin; somatotropin = tillväxthormon.
-tropic / -trop
suffix som har riktning mot, påverkar. Eng. -tropic. Av grek. tropos = vändning, riktning. Ex: kronotrop = som påverkar hjärtats rytm; inotrop = som påverkar hjärtats kraft.
-ula / -ulus / -culum
suffix anatomiska diminutivändelser – liten variant av organet. Av lat. -ula, -ulus, -culum. Ex: venula = litet venöst kärl; divertikulum = liten utbuktning.
-uria / -uri
suffix sjuklig förändring i urinen, urinering. Eng. -uria. Av grek. ouron = urin. Ex: hematuri = blod i urinen; glukosuri = socker i urinen; polyuri.
-valva
suffix klaff, ventil. Eng. valve. Av lat. valva = dörrhalva, klaff. Ex: valvula = liten klaff (t.ex. i ven eller hjärta).
-zyme / -zym
suffix enzym, jäsningsämne. Eng. -zyme. Av grek. zyme = surdeg, jäsning. Ex: lysozym = bakteriedödande enzym. Jfr prefix zym-.

Termer, definitioner och stavning följer vedertagna standardverk inom anatomi och medicinsk terminologi: Terminologia Anatomica (FIPAT/IFAA), Nomina Anatomica, Gray’s Anatomy, Sobotta – Atlas of Human Anatomy, Svenska Akademiens ordbok (SAOB) samt etablerade svenska medicinska uppslagsverk och ordböcker. Diagnoser, koder och läkemedelsuppgifter har även stämts av mot Socialstyrelsens klassifikationer (ICD-10-SE) och FASS.
